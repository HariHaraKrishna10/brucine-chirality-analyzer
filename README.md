# 🧪 Brucine Chirality Analyzer

An interactive web application for analyzing the chirality of the **Brucine** molecule. This project helps chemistry students and researchers understand molecular chirality through a simple and user-friendly interface.

## 🌐 Live Demo

👉 https://brucine-chirality-analyzer-atydlzoi5ptmpvdrxgfmao.streamlit.app/

---

## 📖 About the Project

The Brucine Chirality Analyzer is a Streamlit-based web application developed as a chemistry project. It provides an interactive platform to study the chiral nature of Brucine, visualize molecular information, and improve conceptual understanding of stereochemistry.

This project aims to make learning chemistry more engaging by combining scientific concepts with modern web technologies.

---

## ✨ Features

- 🧬 Analyze the chirality of Brucine
- 📊 Interactive and user-friendly interface
- ⚡ Fast and lightweight web application
- 🌍 Accessible from any device through the browser
- 🎓 Useful for chemistry students, educators, and researchers
